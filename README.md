# Flappy Dusk 🌅

An arcade flight game set against a dusk sky. Thread the pipe gaps, dodge obstacles, and chase your high score.

🎮 **Live Game:** [flappy-dusk.vercel.app](https://flappy-dusk.vercel.app)

---

## About

Flappy Dusk is a responsive, zero-asset web arcade game built for instant play on mobile and desktop browsers with zero loading screens.

### How to Play

- **Mobile:** Tap anywhere on the screen to take off, flap, or fly again.
- **Desktop:** Press <kbd>Space</kbd>, <kbd>W</kbd>, or <kbd>↑</kbd> to flap; press <kbd>R</kbd> to restart.

---

## Features

- **Instant Play:** Zero downloads — visuals are drawn procedurally via HTML5 Canvas, and sound effects are generated in real time using the Web Audio API synthesizer.
- **Mobile Optimized:** Built for touch screens with full-screen tap controls, notch/Dynamic Island safe-area awareness, and mobile haptic vibration feedback.
- **Responsive:** Smooth logical scaling across phones, tablets, and desktop displays in both portrait and landscape orientations.
- **Best Score Tracking:** Automatically persists your personal best score across sessions.
